Dev realm update feed

Use this manifest URL in the launcher Settings when testing Dev:
https://raw.githubusercontent.com/Wrath-of-Azeroth/Wrath-of-Azeroth-Launcher/main/launcher-feed/dev/manifest.json

This feed installs the Dev realm client patch and the managed MobRewardStats and WoARaidFinder addons. Its realmlist points to the Dev login tunnel. The default Live feed is separate and unchanged.
